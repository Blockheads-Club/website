# Открыть сервер для интернета

Позвольте друзьям из других мест заходить в ваш мир. Сначала вы защитите сервер, затем пробросите один порт на роутере.

::: info Что понадобится
- Сервер, который уже работает в вашей сети Wi-Fi ([руководство по локальной сети](./lan-play))
- Доступ к странице настроек роутера
:::

## 1. Сначала защитите сервер

Задайте **пароль**: в приложении в разделе **Настройки** → **Пароль** (до 15 символов) или командой `/set-password` в консоли.

Или включите **белый список**, добавив имена: в приложении в разделе **Списки доступа** → **Белый список** или командой `/whitelist`. Как только в белом списке появляются имена, заходить могут только эти игроки.

```text
# in the server console
/set-password secret123
/whitelist friendname
```

![Экран настроек сервера, раздел подключения: порт 15151, максимум игроков и пароль (до 15 символов).](/shots/ru/server/settings.webp)

*Пароль задаётся в настройках, в разделе подключения.*

## 2. Закрепите за сервером постоянный адрес

В роутере зарезервируйте локальный IP-адрес компьютера с сервером (обычно это называется DHCP-резервирование), чтобы он не менялся после перезагрузки.

## 3. Пробросьте порт

На странице проброса портов роутера направьте **UDP-порт 15151** на локальный адрес компьютера с сервером. Если вы меняли порт, укажите свой.

## 4. Сообщите свой публичный адрес

Узнайте свой публичный IP-адрес и отправьте его друзьям вместе с портом. Они заходят через **Join World** → **Advanced...** → **Online IP/Port...**.

::: warning
Публичный IP примерно показывает, где вы находитесь. Делитесь им только с теми, кому доверяете.
:::

## Если что-то пошло не так

- **Дома работает, снаружи нет** — адрес роутера в интернете может отличаться от вашего публичного IP (некоторые провайдеры выдают один адрес сразу многим клиентам). Тогда проброс портов не сработает — обратитесь к провайдеру.
- **Всё равно не пускает** — проверьте, что брандмауэр на компьютере с сервером разрешает UDP 15151.
- Нужна помощь? [Сообщите о проблеме на GitHub](https://github.com/Blockheads-Club/blockheads-server/issues).
