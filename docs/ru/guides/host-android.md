# Сервер на Android-телефоне

Превратите запасной Android-телефон в сервер. Приложение Blockheads Server работает в фоне, а управлять им можно из уведомления.

::: info Что понадобится
- Android-телефон в вашей сети Wi-Fi
- APK Blockheads Server (`blockheads-server-…-android.apk`, [релизы](https://github.com/Blockheads-Club/blockheads-server/releases))
- Зарядное устройство
:::

## 1. Установите приложение

Скачайте APK и откройте его. Android может попросить разрешить установку из браузера.

## 2. Создайте мир и запустите

Откройте **Миры** → **Создать мир**. Выберите название (до 30 символов) и размер, оставьте включённым **Сразу использовать этот мир** и нажмите **Запустить сервер**.

![Приложение Blockheads Server на телефоне Android, экран миров: кнопка создания мира и миры «Sunny Isle» (загружен сейчас) и «Cozy Harbor».](/shots/ru/server/phone-worlds.webp)

*Создайте мир, затем запустите сервер.*

## 3. Пусть работает в фоне

В уведомлении видны состояние, мир, число игроков онлайн и адрес. Кнопки в нём: **Остановить сервер**, **Скопировать адрес** и **Консоль**.

::: tip
Пока сервер работает, приложение не даёт телефону и его Wi-Fi уснуть. Если телефон всё равно его останавливает, отключите оптимизацию батареи для Blockheads Server в настройках Android.
:::

## 4. Держите телефон на зарядке

Сервер расходует батарею. Пока друзья играют, оставьте телефон на зарядке.

## 5. Подключите друзей

На экране **Обзор** показаны **адрес в локальной сети** и QR-код. На остальных телефонах заходите через **Join World** → **Advanced...** → **Online IP/Port...**.

![Приложение сервера на телефоне Android, панель работающего сервера: адрес в локальной сети, порт и QR-код для других телефонов.](/shots/ru/server/phone-dashboard.webp)

*Друзья подключаются по адресу с панели.*

## Если что-то пошло не так

- **«Сервер неожиданно остановился»** — нажмите на уведомление и выберите **Открыть журнал**, чтобы узнать причину.
- Миры хранятся в закрытом хранилище приложения на этом телефоне.
- Не получается? [Сообщите о проблеме на GitHub](https://github.com/Blockheads-Club/blockheads-server/issues).
