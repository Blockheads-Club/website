# Как получить APK своей игры

Веб-версии и версии Patcher для компьютера нужна игра в виде файла `.apk`. На Android это руководство обычно можно пропустить.

::: info Что понадобится
- The Blockheads, установленная на Android-телефоне
- Для способа через компьютер: USB-кабель и инструмент Android `adb`
:::

## 1. Android? Используйте установленную игру

Приложение Blockheads Patcher для Android само находит игру на телефоне. Нажмите **Взять установленную игру** — файл не нужен. Или нажмите **Выбрать файл APK**, если файл у вас уже есть.

## 2. Скопируйте игру на компьютер

Включите отладку по USB на телефоне, подключите его и узнайте у Android, где лежит игра. Затем скопируйте этот файл:

```sh
adb shell pm path com.noodlecake.blockheads
# package:/data/app/…/base.apk
adb pull /data/app/…/base.apk blockheads.apk
```

::: warning
Если первая команда выводит **больше одной** строки, игра разбита на несколько APK-файлов. Patcher не может безопасно их обработать — нужен полный (универсальный) APK.
:::

## 3. Откройте его в Patcher

Откройте [веб-версию Patcher](https://blockheads.club/patcher/) или приложение для компьютера и перетащите файл. Принимаются **только файлы .apk**. Ничего не загружается в сеть.

![Patcher на компьютере, шаг выбора игры: область, куда можно перетащить APK-файл The Blockheads, и кнопка выбора файла.](/shots/ru/patcher/choose.webp)

*Перетащите файл .apk или выберите его.*

::: tip
Используйте только свою копию и не делитесь APK с другими.
:::

## Если что-то пошло не так

- **«Выберите .apk игры The Blockheads, который вы сохранили с телефона.»** — файл относится к другому приложению.
- **«Установленная игра состоит из нескольких файлов APK…»** — возьмите вместо этого полный (универсальный) APK.
