# Берегите ключ подписи

Каждая исправленная игра подписывается ключом, который хранится только на вашем устройстве. Сделайте его резервную копию, и будущие исправления будут ставиться без удаления игры.

::: info Что понадобится
- Blockheads Patcher (веб, компьютер или Android)
- Надёжное место для одного небольшого файла и пароль, который вы запомните
:::

## 1. Поймите, зачем нужен ключ

Patcher создаёт ключ при первом патче. Android ставит обновление поверх вашей исправленной игры, только если **обе версии подписаны одним ключом**. Новый ключ означает новое удаление игры — и потерю локальных миров, если вы не сделали копию.

::: warning
**Не показывайте его никому.** Тот, у кого есть ваш ключ, может создавать приложения, выдающие себя за обновления вашей игры.
:::

## 2. Экспортируйте резервную копию

Откройте **Ключи подписи** и выберите **Экспорт копии…**. Задайте пароль, повторите его и нажмите **Сохранить копию**. Вы получите файл `.json`, по умолчанию `blockheads-patcher-key.json`.

![Экран ключей подписи в Patcher: ключ с отпечатком SHA-256 и открытая форма экспорта резервной копии с полями пароля и кнопкой сохранения.](/shots/ru/patcher/keys-export.webp)

*Экспортируйте резервную копию ключа подписи с паролем.*

::: tip
Мы не можем восстановить пароль, поэтому запишите его. Без пароля файл не зашифрован, и любой, у кого он окажется, сможет подписывать приложения от вашего имени.
:::

## 3. Перенесите на другое устройство

На новом устройстве откройте **Ключи подписи**, выберите **Импорт ключа** и укажите файл `.json`. Введите пароль копии и нажмите **Использовать ключ**.

Сравните первые и последние четыре пары отпечатка на обоих устройствах, чтобы убедиться, что ключ тот же.

## 4. Если ключ потерян

Без резервной копии обновить игры, исправленные этим ключом, нельзя. Сохраните миры, удалите исправленную игру и примените патч заново с новым ключом. [Как сохранить миры](./backup-worlds)

## Если что-то пошло не так

- Веб-версия Patcher хранит ключ в хранилище браузера для этого сайта. Очистка данных сайта удалит его — сначала экспортируйте копию.
- Импорт принимает только резервные копии `.json`, экспортированные из Patcher.
- Есть вопросы? [Спросите на GitHub](https://github.com/Blockheads-Club/blockheads-patcher/issues).
