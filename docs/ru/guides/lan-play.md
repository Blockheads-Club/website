# Играть с друзьями по одной сети Wi-Fi

Запустите сервер на домашнем компьютере, и все телефоны в вашей сети Wi-Fi смогут зайти в один мир. Это займёт около четырёх минут.

::: info Что понадобится
- Компьютер с Windows, macOS или Linux в той же сети Wi-Fi, что и телефоны
- Blockheads Server — приложение для компьютера или консольный сервер ([загрузки](https://github.com/Blockheads-Club/blockheads-server/releases))
- The Blockheads на каждом телефоне. На современном Android сначала [почините игру](./fix-game-on-phone)
:::

## 1. Запустите сервер

**Приложение для компьютера:** откройте **Миры**, нажмите **Создать мир**, назовите мир и нажмите **Запустить сервер**.

**Командная строка:** распакуйте загрузку для вашего компьютера и создайте мир. Сервер запустится сразу:

```sh
# Linux / macOS, in the unpacked folder
./blockheads_server --new MYWORLD
# Windows (PowerShell)
.\blockheads_server.exe --new MYWORLD
```

![Приложение Blockheads Server на компьютере, окно создания мира: название, размер от 1/16× до 16×, переключатель режима эксперта и кнопка создания.](/shots/ru/server/worlds-create.webp)

*Создание мира: название, размер и при желании режим эксперта.*

::: tip
Консольный сервер останавливается командой `/stop`. Ctrl + C закрывает его без финального сохранения.
:::

## 2. Разрешите доступ через брандмауэр

Сервер использует **UDP-порт 15151**. Когда брандмауэр Windows спросит, разрешите доступ в **частных сетях**. В других системах, если у вас включён брандмауэр, разрешите входящий UDP на порт 15151.

## 3. Узнайте адрес сервера

В приложении для компьютера на экране **Обзор** есть карточка **Подключение с телефона**: в ней **адрес в локальной сети**, порт и QR-кодом. Отсканируйте код камерой телефона, чтобы скопировать адрес.

В командной строке посмотрите локальный IP-адрес компьютера в сетевых настройках, например `192.168.1.42`.

![Панель работающего сервера: статус, 2 игрока онлайн, время работы, текущий мир «Sunny Isle» и карточка подключения с телефона с QR-кодом, адресом 192.168.1.42 и портом 15151.](/shots/ru/server/dashboard.webp)

*На панели видны адрес в локальной сети, порт и QR-код.*

## 4. Зайдите из игры

На каждом телефоне откройте игру и перейдите:

- **Join World** → **Advanced...** → **Online IP/Port...**
- Введите адрес и порт (в поле уже указан `15151`)
- Нажмите **Join Online World**

::: tip
Если на сервере задан пароль, игра его запросит.
:::

## Если что-то пошло не так

- **Никто не может подключиться** — проверьте, что телефоны в той же сети Wi-Fi (не в гостевой) и что брандмауэр разрешает UDP 15151.
- **Одного друга не пускает** — если в белом списке есть имена, заходить могут только они. См. [Админы, модераторы и баны](./admins-mods).
- Не получается? [Сообщите о проблеме на GitHub](https://github.com/Blockheads-Club/blockheads-server/issues) и приложите журнал сервера.
