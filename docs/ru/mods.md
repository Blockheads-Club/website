# Как сделать мод

**Моды** добавляют в The Blockheads новые возможности: команды чата, новые правила, инструменты для администраторов
серверов и, позже, изменения, которые игроки увидят в игре. Что сделали другие, можно посмотреть на <a href="../../mods/" target="_self">странице модов</a>.

::: warning Серверы пока не умеют загружать моды
Инструменты ниже уже работают, но Blockheads Server пока не может загружать моды. Это появится в одном из следующих выпусков.
:::

## Стороны

Мод работает на одной или на обеих **сторонах**:

- **server**: работает на сервере.
- **client**: работает в игре на устройстве игрока.
- **обе**: есть серверная и клиентская часть. Мод можно пометить как *client-required* (обязателен на клиенте), тогда игроки без него не смогут зайти.

## Языки

Мод можно писать на **Lua/Luau** или на **Rust, скомпилированном в WebAssembly (WASM)**. Другие языки появятся позже.

## Установите инструмент

```sh
cargo install --git https://github.com/Blockheads-Club/mod-sdk bhmod
```

Дальше:

```sh
bhmod new my-mod     # создать новый мод из шаблона
bhmod check          # проверить mod.toml и код
bhmod pack           # собрать my-mod-0.1.0.bhmod
```

SDK лежит здесь: [github.com/Blockheads-Club/mod-sdk](https://github.com/Blockheads-Club/mod-sdk).

## mod.toml

У каждого мода есть файл `mod.toml`. Основные поля:

| Поле | Значение |
| --- | --- |
| `id`, `version`, `name`, `description` | Кто этот мод. Id состоит из строчных букв, цифр и `-`. |
| `authors`, `license` | Кто сделал и под какой лицензией. |
| `sides` | `server`, `client` или обе. |
| `api` | С какими версиями API модов он работает. |
| `depends` | Другие моды, которые ему нужны. |
| `permissions` | Что ему разрешено (ниже). |

## Разрешения

Мод может делать только то, что разрешено его правами:

- `world`: `none`, `read` или `write`.
- `players`: любые из `chat`, `teleport`, `kick`, `ban`, `inventory`, `health`.
- `net-http`: сайты, к которым он может подключаться.
- `channels`: собственные сообщения между сервером, клиентами и другими модами.
- `native`: нативный код вне песочницы. Показывается с **красным предупреждением** и проверяется вручную.

Запрашивайте только то, что нужно.

## Публикация

Моды попадают в каталог через pull request в [Blockheads-Club/mods](https://github.com/Blockheads-Club/mods).
Шаги, правила и проверки описаны на странице <a href="../../mods/submit" target="_self">«Отправить мод»</a>.

Каждый новый мод проходит **проверку безопасности**: мейнтейнер читает его код до публикации. Обновления проверяются
снова, если добавляют разрешения или нативный код. Опубликованный список лежит по адресу
[blockheads.club/mods/index.json](https://blockheads.club/mods/index.json); каждая загрузка сверяется с указанными там
SHA-256 и размером.
