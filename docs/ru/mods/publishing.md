# Публикация

Общий список лежит в [Blockheads-Club/mods](https://github.com/Blockheads-Club/mods) и показывается на
<a href="../../../mods/" target="_self">странице модов</a>. Моды добавляются через pull request.

## Перед отправкой

- Добавьте файл `LICENSE` (любая лицензия на ваш вкус).
- Выложите `.bhmod` в открытый доступ по HTTPS, например как файл GitHub-релиза. При слиянии он зеркалируется.
- Проверьте его по правилам общего списка:

  ```sh
  bhmod check . --index
  bhmod pack .
  ```

## Отправка

1. Добавьте один файл `mods/<первая буква>/<id>.toml` с данными мода, ссылкой на загрузку, SHA-256 и размером.
2. Откройте pull request. CI проверит запись и пакет и оставит комментарий с запрошенными разрешениями.
3. Мейнтейнер читает код каждого **нового** мода (и обновлений, добавляющих разрешения или нативный код) до
   публикации в списке.

Все поля и пример: <a href="../../../mods/submit" target="_self">Отправить мод</a>.

## Обновления

- Добавьте в запись новую версию; опубликованные версии никогда не правятся и не удаляются.
- Сломанную версию можно пометить `yanked = true`.
- Менять запись могут только `owners` мода.

Те же проверки, что в CI, можно запустить локально: [`bhmod index validate`](https://github.com/Blockheads-Club/mod-sdk/blob/dev/docs/index.md).
