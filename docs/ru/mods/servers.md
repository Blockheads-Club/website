# Моды на вашем сервере

::: warning Предварительная версия
[Blockheads Server](../server) запускает **Lua**- и **WASM**-моды (Rust) в сборках для разработки; в релизе их пока нет.
Для модов с **клиентской** частью у игроков должен быть загрузчик модов (PC-версия или Android с Patcher).
:::

## Включите моды

Моды загружаются из папки `mods` в папке данных сервера:

| Способ запуска | Папка модов |
| --- | --- |
| Приложение / командная строка | `<папка данных>/mods` (папка данных задаётся через `BLOCKHEADS_DATA_DIR`, иначе это `GNUstep/Library/ApplicationSupport/TheBlockheads` в вашей домашней папке) |
| Docker | `/data/mods` внутри тома |
| Везде | задайте `BLOCKHEADS_MODS_DIR` с другой папкой |

Без папки модов (или с пустой) сервер ведёт себя точно как обычный: те же байты, сохранения и вывод.

## Установите мод

1. Скачайте файл `.bhmod` со <a href="../../../mods/" target="_self">страницы модов</a> (или получите его у автора).
   Распакованная папка мода (с `mod.toml` внутри) тоже подойдёт.
2. Положите его в папку модов.
3. Выдайте ему разрешения в `mods.toml` (ниже).
4. Перезапустите сервер. В логе будет `loaded 1 mod(s): …` или причина, по которой мод не загрузился.

В приложении Server есть и экран «Моды» для папки модов (сборки для разработки).

## mods.toml

`mods.toml` лежит в папке модов. Один раздел на каждый id мода:

```toml
[hello-lua]
grant = ["players:chat"]

[noisy-mod]
enabled = false   # остаётся установленным, но не загружается
```

Моду без разрешений раздел не нужен. Мод, который просит невыданное разрешение, **не загружается**; моды, которые
от него зависят, тоже пропускаются.

## Разрешения {#permissions}

| Разрешение | Позволяет моду |
| --- | --- |
| `players:chat` | отправлять сообщения в чат всем |
| `players:kick`, `players:ban` | кикать или банить игроков |
| `players:teleport`, `players:inventory`, `players:health` | перемещать игроков, менять инвентарь или здоровье |
| `world:read`, `world:write` | читать или менять мир (`world:write` включает и `world:read`) |
| `net-http:<host>` | обращаться к этому сайту |
| `channels` | отправлять сообщения другим модам и клиентам |
| `native` | запускать нативный код вне песочницы (**красное предупреждение**, проверка вручную) |

Всё остальное разрешений не требует: события, собственные команды, таймеры, собственное хранилище, чат одному
игроку и сервисы модов, от которых он зависит. Что просит мод, видно на его странице в общем списке.

## Ограничения по времени и памяти {#time-and-memory-limits}

Моды работают в главном потоке сервера, поэтому каждый из них держится на коротком поводке:

- Каждый вызов в мод может занимать **25 мс** (после 5 мс в лог пишется предупреждение).
- Все моды вместе получают **20 мс** на шаг мира; таймеры сверх этого ждут следующего шага.
- Каждому моду выделяется **32 МиБ** памяти.

Ошибка, превышение времени или нехватка памяти считаются **сбоем**. **3 сбоя за 60 с отключают мод** до следующего
перезапуска; в логе будет `disabled: 3 faults within 60 s` и название ошибки. Сообщите об этом автору мода.

## Хранилище

Каждый мод хранит свои данные отдельно для каждого мира в `saves/<world>/mods/storage`, не смешивая их с самим
миром. Если удалить эту папку, данные модов сбросятся, а мир не пострадает. Делайте её резервную копию вместе с миром.

## Игроки с обычной игрой

- **Только серверные моды:** зайти может любой с обычной игрой.
- **Моды, обязательные на клиенте** <Badge type="info" text="превью" />: игроков без загрузчика модов не пускают
  (их игра пишет, что клиент устарел). На странице мода такие моды помечены как *client-required*.
