# Сервер

**Blockheads Server** запускает многопользовательские миры для вас и ваших друзей. Это бесплатная переписанная с нуля
версия выделенного сервера игры (версии 1.7.1) с открытым кодом, поэтому игра и существующие миры работают с ним без
изменений.

Скачать можно на [странице релизов](https://github.com/Blockheads-Club/blockheads-server/releases).

## Приложение для компьютера

Самый простой способ на компьютере. Скачайте приложение для своей системы:

| Система | Файл |
| --- | --- |
| Windows | `_x64-setup.exe` (`arm64` для ARM-компьютеров) |
| macOS | `_x64.dmg` (Intel) или `_aarch64.dmg` (Apple Silicon) |
| Linux | `.AppImage`, `.deb` или `.rpm` |

Затем:

1. **Создать мир** (название, размер, при желании режим эксперта).
2. Нажмите **Запустить сервер**.
3. Поделитесь с друзьями адресом, который показывает приложение. Для телефонов есть и QR-код.

## Командная строка

Для серверов без экрана или если вам удобнее терминал. Скачайте архив для своей системы (`x86_64`, `aarch64` или
`armv7` для Raspberry Pi), распакуйте и запустите:

```sh
./blockheads_server --new world1 --port 15151
```

В Windows (PowerShell):

```powershell
.\blockheads_server.exe --new world1 --port 15151
```

**macOS:** При первом запуске снимите отметку о загрузке, чтобы Gatekeeper разрешил программу:

```sh
xattr -d com.apple.quarantine ./blockheads_server
```

Запустите с `--help`, чтобы увидеть все параметры. Они такие же, как у оригинального сервера.

Миры сохраняются в папке `GNUstep/Library/ApplicationSupport/TheBlockheads` в вашей домашней папке. Чтобы
использовать другую папку, задайте переменную окружения `BLOCKHEADS_DATA_DIR`.

## Docker

```sh
docker run -i --rm -p 15151:15151/udp -v bh-data:/data \
  ghcr.io/blockheads-club/blockheads-server:0.1.1 --new MYWORLD
```

- Не убирайте `-i`, чтобы можно было писать в консоль (`/stop`, чат).
- Миры хранятся в томе `bh-data` и сохраняются после обновлений.
- Образ работает на x86_64 и ARM.

## Android

1. Скачайте `blockheads-server-…-android.apk` и откройте его для установки. Android может попросить разрешить
   установку из браузера.
2. Создайте мир и нажмите **Запустить сервер**. Сервер продолжит работать в фоне; уведомление показывает его состояние.
3. Держите телефон на зарядке. Если приложение попросит, отключите для него оптимизацию батареи, чтобы Android его не
   остановил.

## Подключение из игры {#connect-from-the-game}

1. Запустите сервер и запишите его адрес и порт, например `192.168.1.42` и порт `15151`.
2. В игре откройте **Join World → Advanced… → Online IP/Port…**
3. Введите адрес и порт и подключитесь. Если у сервера есть пароль, игра его спросит.

::: tip Игрокам на Android
Современным Android-версиям игры нужно исправление приветственного окна из [Patcher](/ru/patcher), иначе они не смогут
подключиться к серверу.
:::

## LAN (одна сеть Wi-Fi)

Проще всего играть вместе в одной сети:

- Телефон (или компьютер) и сервер должны быть в **одной сети Wi-Fi или одной локальной сети**.
- Используйте **адрес в локальной сети**, который показывает сервер (начинается с `192.168.`, `10.` или похоже).
  На телефоне отсканируйте QR-код, чтобы скопировать его.
- Порт по умолчанию — **15151** (UDP). Если друзья не могут подключиться, проверьте адрес и порт и разрешите сервер
  в брандмауэре.

::: warning Играете через интернет?
Пробросьте UDP-порт 15151 на роутере на компьютер с сервером и сообщите друзьям свой внешний IP. Сначала задайте
пароль или включите белый список.
:::
