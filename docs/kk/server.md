# Сервер

**Blockheads Server** сізге және достарыңызға көп ойыншы әлемдерін іске қосады. Бұл — ойынның арнайы серверінің
(1.7.1 нұсқасы) тегін әрі ашық кодпен қайта жазылған нұсқасы, сондықтан ойын мен бар әлемдер онымен өзгеріссіз жұмыс
істейді.

[Шығарылымдар бетінен](https://github.com/Blockheads-Club/blockheads-server/releases) жүктеп алыңыз.

## Компьютерге арналған қолданба

Компьютердегі ең оңай жол. Жүйеңізге сай қолданбаны жүктеп алыңыз:

| Жүйе | Файл |
| --- | --- |
| Windows | `_x64-setup.exe` (ARM компьютерлерге `arm64`) |
| macOS | `_x64.dmg` (Intel) немесе `_aarch64.dmg` (Apple Silicon) |
| Linux | `.AppImage`, `.deb` немесе `.rpm` |

Содан кейін:

1. **Әлем жасау** (атауы, өлшемі, қаласаңыз сарапшы режимі).
2. **Серверді іске қосу** түймесін басыңыз.
3. Қолданба көрсететін мекенжайды достарыңызбен бөлісіңіз. Телефондар үшін QR-код та бар.

## Пәрмен жолы

Экраны жоқ серверлерге немесе терминал ыңғайлы болса. Жүйеңізге сай архивті (`x86_64`, `aarch64` немесе Raspberry Pi
үшін `armv7`) жүктеп алып, ашыңыз да, іске қосыңыз:

```sh
./blockheads_server --new world1 --port 15151
```

Windows-та (PowerShell):

```powershell
.\blockheads_server.exe --new world1 --port 15151
```

Барлық параметрлерді көру үшін `--help` арқылы іске қосыңыз. Олар бастапқы сервердегідей.

Әлемдер үй қалтаңыздағы `GNUstep/Library/ApplicationSupport/TheBlockheads` қалтасына сақталады. Басқа қалтаны
пайдалану үшін `BLOCKHEADS_DATA_DIR` орта айнымалысын орнатыңыз.

## Docker

```sh
docker run -i --rm -p 15151:15151/udp -v bh-data:/data \
  ghcr.io/blockheads-club/blockheads-server:0.1.1 --new MYWORLD
```

- Консольге жаза алу үшін (`/stop`, чат) `-i` қалсын.
- Әлемдеріңіз `bh-data` томында сақталады, сондықтан жаңартулардан кейін де жоғалмайды.
- Docker образы x86_64 және ARM жүйелерінде жұмыс істейді.

## Android

1. `blockheads-server-…-android.apk` файлын жүктеп алып, орнату үшін ашыңыз. Android браузерден орнатуға рұқсат
   сұрауы мүмкін.
2. Әлем жасап, **Серверді іске қосу** түймесін түртіңіз. Сервер фонда жұмысын жалғастырады; хабарландыру оның күйін
   көрсетеді.
3. Телефонды зарядта ұстаңыз. Қолданба сұраса, Android оны тоқтатпауы үшін батареяны оңтайландыруды өшіріңіз.

![Android телефонындағы Blockheads Server қолданбасы: жұмыс істеп тұрған сервер тақтасы, жергілікті желі мекенжайы, порт және басқа телефондарға QR-код.](/shots/kk/server/phone-dashboard.webp)

*Android қолданбасында да сол тақта бар.*

## Ойыннан қосылу {#connect-from-the-game}

1. Серверді іске қосып, мекенжайы мен портын жазып алыңыз, мысалы `192.168.1.42` және порт `15151`.
2. Ойында **Join World → Advanced… → Online IP/Port…** тармағын ашыңыз.
3. Мекенжай мен портты енгізіп, қосылыңыз. Серверде құпиясөз болса, ойын оны сұрайды.

::: tip Android ойыншыларына
Ойынның қазіргі Android нұсқалары серверге қосылу үшін [Патчердегі](/kk/patcher) қарсы алу терезесін түзетуді қажет
етеді.
:::

## LAN (бір Wi-Fi желісі)

Бірге ойнаудың ең оңай жолы — бір желіде болу:

- Телефон (не компьютер) мен сервер **бір Wi-Fi желісінде немесе бір жергілікті желіде** болуы керек.
- Сервер көрсететін **жергілікті желі мекенжайын** қолданыңыз (`192.168.`, `10.` немесе соған ұқсас басталады).
  Телефонда оны көшіру үшін QR-кодты сканерлеңіз.
- Әдепкі порт — **15151** (UDP). Достарыңыз қосыла алмаса, мекенжай мен портты тексеріп, брандмауэрде серверге рұқсат
  беріңіз.

::: warning Интернет арқылы ойнайсыз ба?
Роутерде UDP 15151 портын сервер компьютеріне бағыттап, сыртқы IP мекенжайыңызды бөлісіңіз. Алдымен құпиясөз
орнатыңыз немесе ақ тізімді қосыңыз.
:::
