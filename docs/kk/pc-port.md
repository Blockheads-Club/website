# PC нұсқасы

**Blockheads PC** Android ойынының өз көшірмеңізді компьютерде іске қосады. Windows, macOS және Linux жүйелерінде,
қарапайым (x86_64) және ARM (arm64) компьютерлерде жұмыс істейді.

::: warning Алғашқы нұсқа
PC нұсқасы жаңа ғана шықты. Ойынның көп бөлігі жұмыс істейді, бірақ кейбір кемшіліктер болуы мүмкін. Тапқан
мәселелеріңіз туралы [хабарлаңыз](https://github.com/Blockheads-Club/blockheads-pc/issues).
:::

::: info Қолданба тілі
Blockheads PC қолданбасы әзірге ағылшын және түрік тілдерінде ғана бар. Төменде түймелер мен баптаулардың атаулары
қолданбадағыдай берілген.
:::

## Жүктеп алу және орнату {#download-and-install}

Соңғы нұсқаны [шығарылымдар бетінен](https://github.com/Blockheads-Club/blockheads-pc/releases) жүктеп алыңыз.
Жүйеңізге сай файлды таңдаңыз:

| Жүйе | Файл |
| --- | --- |
| Linux | `.AppImage`, `.deb` немесе `.rpm` (`amd64`/`x86_64` не `arm64`/`aarch64`) |
| Windows | `_x64-setup.exe` немесе `_x64_en-US.msi` (ARM компьютерлерге `arm64`) |
| macOS (Intel) | `_x64.dmg` |
| macOS (Apple Silicon) | `_aarch64.dmg` |

### Linux

- **AppImage** (кез келген дистрибутивте): файлды орындалатын етіп, іске қосыңыз.
  ```sh
  chmod +x Blockheads*.AppImage
  ./Blockheads*.AppImage
  ```
- **Debian, Ubuntu**: `sudo apt install ./Blockheads*.deb`
- **Fedora, openSUSE**: `sudo dnf install ./Blockheads*.rpm`

### Windows

`setup.exe` файлын (тек сіздің пайдаланушыңызға орнатады, әкімші құқығы керек емес) немесе `.msi` файлын іске қосыңыз.

::: tip «Windows компьютеріңізді қорғады»
Орнатқыш әзірге кодпен қол қойылмаған, сондықтан SmartScreen ескерту көрсетуі мүмкін. **Толығырақ** түймесін, содан
кейін **Бәрібір іске қосу** түймесін басыңыз.
:::

### macOS

`.dmg` файлын ашып, лицензияны қабылдаңыз да, **Blockheads PC** қолданбасын **Applications** (Бағдарламалар) қалтасына
сүйреңіз.

::: tip «Blockheads PC ашылмайды»
Қолданба Apple тарапынан нотариалды тексеруден өтпеген. Бірінші рет қолданбаны **тінтуірдің оң жағымен басып**,
**Open** (Ашу) пәрменін таңдаңыз. Немесе **System Settings → Privacy & Security** бөліміне өтіп, **Open Anyway**
түймесін басыңыз.
:::

## Алғашқы іске қосу: ойын файлы

Blockheads PC-ні алғаш ашқанда қысқа баптау қадамдары сізге жол көрсетеді:

1. **Welcome** — ойын сізде бар екенін және тек өз көшірмеңізді қолданатыныңызды растаңыз.
2. **Game file** — APK файлын таңдаңыз немесе терезеге сүйреп әкеліңіз.
3. **Window & graphics** — терезе өлшемі мен сурет баптаулары.
4. **Controls** — тінтуір түймелері мен пернелерді тексеріңіз.
5. **Import saves** — міндетті емес: ойынның сақтаулар қалтасын телефоннан (немесе zip сақтық көшірмесін) көшіріп,
   осы жерде таңдаңыз.
6. **Ready** — қорытынды. **Play** түймесін басыңыз.

Мұның бәрін кейін **Settings** бөлімінде өзгертуге болады.

### Өз APK файлыңыз

Blockheads PC-ге өзіңізге тиесілі The Blockheads ойынының APK файлы керек: **1.7.4, 1.7.5 немесе 1.7.6** нұсқасы.
Оны телефоннан компьютерге көшіріп, баптау кезінде таңдаңыз. Біз ойынды ешқашан жүктемейміз және таратпаймыз.

- **Keep a private copy in the data folder** баптауын қосулы қалдырыңыз (ұсынылады). Сонда бастапқы файлды жылжытсаңыз
  не өшірсеңіз де, ойын жұмысын жалғастырады.
- Басқа нұсқаларды немесе өзгертілген APK файлдарын **Advanced → Allow unknown builds** арқылы байқап көруге болады.
  Олар іске қосылмауы мүмкін.

## Баптаулар

| Бөлім | Нені өзгертуге болады |
| --- | --- |
| **Game & data** | Ойын файлы және әлемдеріңіз сақталатын деректер қалтасы |
| **Window & graphics** | Терезе өлшемі не толық экран, VSync, FPS шегі, FPS есептегіші, ойын интерфейсінің масштабы, ойын жылдамдығы |
| **Controls** | Тінтуір мен пернетақта тағайындаулары, геймпад, экрандағы D-pad |
| **Audio** | Дыбысты қосу және өшіру (дыбыс деңгейі ойынның ішінде реттеледі) |
| **Language & theme** | Тіл, ашық не қараңғы тақырып |
| **Updates & about** | Нұсқа, жаңартулар және лицензиялар |

### Графика және FPS

- **Fullscreen** (толық экран): баптаулардан қосыңыз немесе ойын кезінде **F11** пернесін басыңыз.
- **VSync**: үзіліссіз, біркелкі сурет. Ойын баяу жауап берген жағдайда ғана өшіріңіз.
- **FPS limit** (FPS шегі): ең жоғары кадр жиілігі. Телефондағы ойын 30 FPS-пен жүреді; жоғарырақ шек суретті
  біркелкі етеді, бірақ ойынды жылдамдатпайды. Төмен шек қуатты үнемдеп, ноутбукты салқын ұстайды.
- **Show FPS**: шағын кадр жиілігі есептегіші. Оның қай бұрышта тұратынын таңдауға болады.
- **Game UI scale**: ойындағы түймелер мен мәтінді үлкейтеді не кішірейтеді.

### Ойын жылдамдығы

**Game speed** әлемді жылдамырақ жүргізеді: жүру, күн мен түннің ауысуы, егін, аштық және тағы басқасы. Тек жалғыз
ойыншы режимінде жұмыс істейді; көп ойыншы ойындары әрдайым қалыпты жылдамдықта жүреді.

### Басқару

Ойын сенсорлы экранға арналып жасалған, сондықтан тінтуір саусақтың орнын басады:

| Тінтуір / перне | Әрекеті |
| --- | --- |
| Сол жақ түйме | Түрту және сүйреу (ұзақ басу үшін ұстап тұрыңыз) |
| Оң жақ түймемен сүйреу | Көріністі жылжыту |
| Тінтуір дөңгелегі | Жақындату және алыстату |
| Esc | Артқа |
| F11 | Толық экранды қосу не өшіру |
| H | Ойын түймелерін жасыру не көрсету |

Мұның бәрін **Settings → Controls** бөлімінде қайта тағайындауға немесе әдепкі мәндерге қайтаруға болады.

### Геймпад

Геймпадты кез келген уақытта қосыңыз; бірінші қосылғаны ойнайды. Курсор **A** түймесі қай жерді түртетінін көрсетеді.

| Түйме | Әрекеті |
| --- | --- |
| Сол жақ таяқша | Жүру |
| Оң жақ таяқша | Курсорды жылжыту |
| D-pad | Курсорды бір блокқа жылжыту, мәзірлерде де |
| A | Түрту; қазу не сүйреу үшін ұстап тұрыңыз |
| B | Артқа |
| X | Ойын түймелерін жасыру не көрсету |
| Y | Келесі масштаб деңгейі |
| LB / RB | Алыстату / жақындату |
| Start | Үзіліс мәзірі |

Курсор блоктан блокқа секіріп жүрсін десеңіз, **Move the controller cursor tile by tile** баптауын қосыңыз.

### Экрандағы D-pad

Телефондағы ойын әлемде экранға бағыт түймелерін салады. PC-де олар жасырын, себебі тінтуір, пернетақта және геймпад
блокхедіңізді онсыз да қозғайды. Оларды қайтарғыңыз келсе, **Show the game’s on-screen D-pad** баптауын қосыңыз.

## Желіде ойнау

Серверлерге телефондағыдай қосыла аласыз. Мекенжай арқылы қосылу үшін ойында **Join World → Advanced… → Online IP/Port…**
тармағын ашып, мекенжай мен портты енгізіңіз де, **Join Online World** түймесін басыңыз. Толығырақ:
[Сервер](/kk/server#connect-from-the-game) беті.

## Ақауларды жою

- **Алғашқы іске қосу ұзаққа созылады.** Ойынның жүктелуі бірнеше секундқа созылады, бірінші рет ұзағырақ. Жүктеу
  экраны барысын көрсетеді.
- **«This isn’t The Blockheads» / «This build isn’t supported».** The Blockheads ойынының 1.7.4, 1.7.5 немесе 1.7.6
  нұсқасының APK файлын таңдаңыз.
- **«The file is damaged».** Файл толық көшірілмеген. APK файлын телефоннан қайта көшіріңіз.
- **«We can’t find your game file».** Файлды жылжытқансыз не өшіргенсіз, ал жеке көшірме сақталмаған. Файлды қайта
  таңдаңыз; әлемдеріңізге әсер етпейді.
- **Ойын кенеттен жабылып қалды.** Журнал сақталады. Басты экрандағы **Report on GitHub** түймесін басыңыз немесе
  журналдарды **View logs** арқылы ашып, [қате туралы хабарламаңызға](https://github.com/Blockheads-Club/blockheads-pc/issues)
  тіркеңіз.
- **Ойын баяу жүреді.** Күрделі көріністер телефондағыдан баяуырақ жүруі мүмкін. Ауыр бағдарламаларды жауып,
  бейнекарта драйверлерін жаңартыңыз.
- **Windows немесе macOS қолданбаны бұғаттайды.** [Жүктеп алу және орнату](#download-and-install) бөліміндегі
  кеңестерді қараңыз.
- **Әлемдерім қайда?** Басты экрандағы **Open data folder** түймесін басыңыз.
