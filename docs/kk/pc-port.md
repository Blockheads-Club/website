# Blockheads PC

**Blockheads PC** Android ойынының өз көшірмеңізді компьютерде іске қосады. Windows, macOS және Linux жүйелерінде,
қарапайым (x86_64) және ARM (arm64) компьютерлерде жұмыс істейді.

::: warning Алғашқы нұсқа
Blockheads PC жаңа ғана шықты. Ойынның көп бөлігі жұмыс істейді, бірақ кейбір кемшіліктер болуы мүмкін. Тапқан
мәселелеріңіз туралы [хабарлаңыз](https://github.com/Blockheads-Club/blockheads-pc/issues).
:::

## Жүктеп алу және орнату {#download-and-install}

Соңғы нұсқаны [шығарылымдар бетінен](https://github.com/Blockheads-Club/blockheads-pc/releases) жүктеп алыңыз.
Жүйеңізге сай файлды таңдаңыз:

| Жүйе | Файл |
| --- | --- |
| Linux | `.AppImage`, `.deb` немесе `.rpm` (`amd64`/`x86_64` не `arm64`/`aarch64`) |
| Windows | `_x64-setup.exe` немесе `_x64_en-US.msi` (ARM компьютерлерге `arm64`) |
| macOS (Intel) | `_x64.dmg` |
| macOS (Apple Silicon) | `_aarch64.dmg` |

### Linux

- **AppImage** (кез келген дистрибутивте): файлды орындалатын етіп, іске қосыңыз.
  ```sh
  chmod +x Blockheads*.AppImage
  ./Blockheads*.AppImage
  ```
- **Debian, Ubuntu**: `sudo apt install ./Blockheads*.deb`
- **Fedora, openSUSE**: `sudo dnf install ./Blockheads*.rpm`

### Windows

`setup.exe` файлын (тек сіздің пайдаланушыңызға орнатады, әкімші құқығы керек емес) немесе `.msi` файлын іске қосыңыз.

::: tip «Windows компьютеріңізді қорғады»
Орнатқыш әзірге кодпен қол қойылмаған, сондықтан SmartScreen ескерту көрсетуі мүмкін. **Толығырақ** түймесін, содан
кейін **Бәрібір іске қосу** түймесін басыңыз.
:::

### macOS

`.dmg` файлын ашып, лицензияны қабылдаңыз да, **Blockheads PC** қолданбасын **Applications** (Бағдарламалар) қалтасына
сүйреңіз.

::: tip «Blockheads PC ашылмайды»
Қолданба Apple тарапынан нотариалды тексеруден өтпеген. Бірінші рет қолданбаны **тінтуірдің оң жағымен басып**,
**Open** (Ашу) пәрменін таңдаңыз. Немесе **System Settings → Privacy & Security** бөліміне өтіп, **Open Anyway**
түймесін басыңыз.
:::

## Алғашқы іске қосу: ойын файлы

Blockheads PC-ні алғаш ашқанда қысқа баптау қадамдары сізге жол көрсетеді:

1. **Қош келдіңіз** — ойын сізде бар екенін және тек өз көшірмеңізді қолданатыныңызды растаңыз.
2. **Ойын файлы** — APK файлын таңдаңыз немесе терезеге сүйреп әкеліңіз.
3. **Терезе және графика** — терезе өлшемі мен сурет баптаулары.
4. **Басқару** — тінтуір түймелері мен пернелерді тексеріңіз.
5. **Сақтауларды импорттау** — міндетті емес: ойынның сақтаулар қалтасын телефоннан (немесе zip сақтық көшірмесін) көшіріп,
   осы жерде таңдаңыз.
6. **Дайын** — қорытынды. **Ойнау** түймесін басыңыз.

![Blockheads PC баптауы, 6 қадамның 2-сі «Ойын файлын таңдаңыз»: The Blockheads 1.7.6 таңдалған, «Қолдау көрсетіледі» белгісі бар, деректер қалтасында жеке көшірме сақтау қосулы.](/shots/kk/pc/setup-2-apk.webp)

*Баптаудың 2-қадамы: өз APK файлыңызды таңдаңыз. Лаунчер нұсқасын тексереді.*

Мұның бәрін кейін **Баптаулар** бөлімінде өзгертуге болады.

### Өз APK файлыңыз

Blockheads PC-ге өзіңізге тиесілі The Blockheads ойынының APK файлы керек: **1.7.4, 1.7.5 немесе 1.7.6** нұсқасы.
Оны телефоннан компьютерге көшіріп, баптау кезінде таңдаңыз. Біз ойынды ешқашан жүктемейміз және таратпаймыз.

- **Деректер қалтасында жеке көшірмесін сақтау** баптауын қосулы қалдырыңыз (ұсынылады). Сонда бастапқы файлды жылжытсаңыз
  не өшірсеңіз де, ойын жұмысын жалғастырады.
- Басқа нұсқаларды немесе өзгертілген APK файлдарын **Қосымша → Белгісіз жинақтарға рұқсат ету** арқылы байқап көруге болады.
  Олар іске қосылмауы мүмкін.

![Blockheads PC басты экраны: The Blockheads 1.7.6 үшін үлкен «Ойнау» түймесі және ойын файлын ауыстыру, сақтауларды импорттау, деректер қалтасын ашу, журналдарды көру және серверге қосылу түймелері.](/shots/kk/pc/home.webp)

*Баптаудан кейінгі басты экран.*

## Баптаулар

| Бөлім | Нені өзгертуге болады |
| --- | --- |
| **Ойын және деректер** | Ойын файлы және әлемдеріңіз сақталатын деректер қалтасы |
| **Терезе және графика** | Терезе өлшемі не толық экран, VSync, FPS шегі, FPS есептегіші, ойын интерфейсінің масштабы, ойын жылдамдығы |
| **Басқару** | Тінтуір мен пернетақта тағайындаулары, геймпад, экрандағы D-pad |
| **Дыбыс** | Дыбысты қосу және өшіру (дыбыс деңгейі ойынның ішінде реттеледі) |
| **Тіл және тақырып** | Тіл, ашық не қараңғы тақырып |
| **Жаңарту және ақпарат** | Нұсқа, жаңартулар және лицензиялар |

### Графика және FPS

![Blockheads PC баптаулары, «Терезе және графика»: терезе не толық экран, терезе өлшемі 1600 × 900, VSync қосулы, 60 FPS шегі, FPS көрсету және ойын жылдамдығы.](/shots/kk/pc/settings-graphics.webp)

*Баптаулар → Терезе және графика.*

- **Толық экран**: баптаулардан қосыңыз немесе ойын кезінде **F11** пернесін басыңыз.
- **VSync**: үзіліссіз, біркелкі сурет. Ойын баяу жауап берген жағдайда ғана өшіріңіз.
- **FPS шегі**: ең жоғары кадр жиілігі. Телефондағы ойын 30 FPS-пен жүреді; жоғарырақ шек суретті
  біркелкі етеді, бірақ ойынды жылдамдатпайды. Төмен шек қуатты үнемдеп, ноутбукты салқын ұстайды.
- **FPS көрсету**: шағын кадр жиілігі есептегіші. Оның қай бұрышта тұратынын таңдауға болады.
- **Ойын интерфейсінің масштабы**: ойындағы түймелер мен мәтінді үлкейтеді не кішірейтеді.

### Ойын жылдамдығы

**Ойын жылдамдығы** әлемді жылдамырақ жүргізеді: жүру, күн мен түннің ауысуы, егін, аштық және тағы басқасы. Тек жалғыз
ойыншы режимінде жұмыс істейді; көп ойыншы ойындары әрдайым қалыпты жылдамдықта жүреді.

### Басқару

![Blockheads PC баптаулары, «Басқару»: ойынның экрандағы D-pad қосқышы және түрту мен сүйреу, жылжыту, масштаб, қысу, артқа тінтуір тағайындаулары, әрқайсысында «Өзгерту» түймесі.](/shots/kk/pc/settings-controls.webp)

*Баптаулар → Басқару: кез келген тағайындауды өзгертуге болады.*

Ойын сенсорлы экранға арналып жасалған, сондықтан тінтуір саусақтың орнын басады:

| Тінтуір / перне | Әрекеті |
| --- | --- |
| Сол жақ түйме | Түрту және сүйреу (ұзақ басу үшін ұстап тұрыңыз) |
| Оң жақ түймемен сүйреу | Көріністі жылжыту |
| Тінтуір дөңгелегі | Жақындату және алыстату |
| Esc | Артқа |
| F11 | Толық экранды қосу не өшіру |
| H | Ойын түймелерін жасыру не көрсету |

Мұның бәрін **Баптаулар → Басқару** бөлімінде қайта тағайындауға немесе әдепкі мәндерге қайтаруға болады.

### Геймпад

![Blockheads PC баптаулары, «Геймпад»: геймпадты қолдану және курсорды тор бойынша жылжыту қосқыштары, геймпад түймелері мен олардың әрекеттерінің кестесі.](/shots/kk/pc/settings-controller.webp)

*Геймпад бөлімі әр түйменің не істейтінін көрсетеді.*

Геймпадты кез келген уақытта қосыңыз; бірінші қосылғаны ойнайды. Курсор **A** түймесі қай жерді түртетінін көрсетеді.

| Түйме | Әрекеті |
| --- | --- |
| Сол таяқша | Жүру |
| Оң таяқша | Курсорды жылжыту |
| D-pad | Курсорды бір блокқа жылжыту, мәзірлерде де |
| A | Түрту; қазу не сүйреу үшін ұстап тұрыңыз |
| B | Артқа |
| X | Ойын түймелерін жасыру не көрсету |
| Y | Келесі масштаб деңгейі |
| LB / RB | Алыстату / жақындату |
| Start | Үзіліс мәзірі |

Курсор блоктан блокқа секіріп жүрсін десеңіз, **Геймпад курсорын блок бойынша жылжыту** баптауын қосыңыз.

### Экрандағы D-pad

Телефондағы ойын әлемде экранға бағыт түймелерін салады. PC-де олар жасырын, себебі тінтуір, пернетақта және геймпад
блокхедіңізді онсыз да қозғайды. Оларды қайтарғыңыз келсе, **Ойынның экрандағы D-pad тақтасын көрсету** баптауын қосыңыз.

## Желіде ойнау

Серверлерге телефондағыдай қосыла аласыз. Мекенжай арқылы қосылу үшін ойында **Join World → Advanced… → Online IP/Port…**
тармағын ашып, мекенжай мен портты енгізіңіз де, **Join Online World** түймесін басыңыз. Толығырақ:
[Сервер](/kk/server#connect-from-the-game) беті.

## Ақауларды жою

- **Алғашқы іске қосу ұзаққа созылады.** Ойынның жүктелуі бірнеше секундқа созылады, бірінші рет ұзағырақ. Жүктеу
  экраны барысын көрсетеді.
- **«Бұл The Blockheads емес» / «Бұл жинаққа қолдау жоқ».** The Blockheads ойынының 1.7.4, 1.7.5 немесе 1.7.6
  нұсқасының APK файлын таңдаңыз.
- **«Файл зақымдалған».** Файл толық көшірілмеген. APK файлын телефоннан қайта көшіріңіз.
- **«Ойын файлыңыз табылмады».** Файлды жылжытқансыз не өшіргенсіз, ал жеке көшірме сақталмаған. Файлды қайта
  таңдаңыз; әлемдеріңізге әсер етпейді.
- **Ойын кенеттен жабылып қалды.** Журнал сақталады. Басты экрандағы **GitHub-та хабарлау** түймесін басыңыз немесе
  журналдарды **Журналдарды қарау** арқылы ашып, [қате туралы хабарламаңызға](https://github.com/Blockheads-Club/blockheads-pc/issues)
  тіркеңіз.
- **Ойын баяу жүреді.** Күрделі көріністер телефондағыдан баяуырақ жүруі мүмкін. Ауыр бағдарламаларды жауып,
  бейнекарта драйверлерін жаңартыңыз.
- **Windows немесе macOS қолданбаны бұғаттайды.** [Жүктеп алу және орнату](#download-and-install) бөліміндегі
  кеңестерді қараңыз.
- **Әлемдерім қайда?** Басты экрандағы **Деректер қалтасын ашу** түймесін басыңыз.
