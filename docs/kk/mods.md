# Мод жасау

**Модтар** The Blockheads ойынына жаңа мүмкіндіктер қосады: чат пәрмендері, жаңа ережелер, сервер әкімшілеріне арналған құралдар және кейінірек ойыншылар ойында көретін өзгерістер. Басқалар жасағанды <a href="../../mods/" target="_self">Модтар бетінен</a> көре аласыз.

::: warning Серверлер әзірге модтарды жүктей алмайды
Төмендегі мод құралдары қазір жұмыс істейді, бірақ Blockheads Server әзірге модтарды жүктей алмайды. Ол келесі шығарылымдардың бірінде болады.
:::

## Тараптар

Мод бір немесе екі **тарапта** жұмыс істейді:

- **server**: серверде жұмыс істейді.
- **client**: ойыншының құрылғысында, ойын ішінде жұмыс істейді.
- **екеуі де**: сервер және клиент бөлігі бар. Оны *client-required* (клиентте міндетті) деп белгілеуге болады, сонда модсыз ойыншылар қосыла алмайды.

## Тілдер

Модты **Lua/Luau** немесе **WebAssembly (WASM)** үшін құрастырылған **Rust** тілінде жазуға болады. Басқа тілдер кейін қосылады.

## Құралды орнатыңыз

```sh
cargo install --git https://github.com/Blockheads-Club/mod-sdk bhmod
```

Содан кейін:

```sh
bhmod new my-mod     # үлгіден жаңа мод жасайды
bhmod check          # mod.toml мен кодты тексереді
bhmod pack           # my-mod-0.1.0.bhmod файлын жасайды
```

SDK мұнда: [github.com/Blockheads-Club/mod-sdk](https://github.com/Blockheads-Club/mod-sdk).

## mod.toml

Әр модтың `mod.toml` файлы бар. Негізгі өрістер:

| Өріс | Мағынасы |
| --- | --- |
| `id`, `version`, `name`, `description` | Модтың кім екені. Id кіші әріптерден, цифрлардан және `-` белгісінен тұрады. |
| `authors`, `license` | Кім жасады және қандай лицензиямен. |
| `sides` | `server`, `client` немесе екеуі. |
| `api` | Қай мод API нұсқаларымен жұмыс істейді. |
| `depends` | Оған қажет басқа модтар. |
| `permissions` | Оған не істеуге рұқсат (төменде). |

## Рұқсаттар

Мод тек рұқсаттары мүмкіндік беретінін ғана істей алады:

- `world`: `none`, `read` немесе `write`.
- `players`: `chat`, `teleport`, `kick`, `ban`, `inventory`, `health` мәндерінің кез келгені.
- `net-http`: қосыла алатын сайттар.
- `channels`: сервер, клиенттер және басқа модтар арасындағы өз хабарлары.
- `native`: құмсалғыштан тыс нативті код. **Қызыл ескертумен** көрсетіледі және қолмен тексеріледі.

Тек қажетін ғана сұраңыз.
