# Мод жасау

**Модтар** The Blockheads ойынына жаңа мүмкіндіктер қосады: чат пәрмендері, жаңа ережелер, сервер әкімшілеріне арналған құралдар және кейінірек ойыншылар ойында көретін өзгерістер. Басқалар жасағанды <a href="../../mods/" target="_self">Модтар бетінен</a> көре аласыз.

::: warning Бүгін не жұмыс істейді
`bhmod` (жасау, тексеру, буып-түю) жұмыс істейді, ал [Blockheads Server](./server) әзірлеу құрастырмаларында **Lua** және **WASM** (Rust) модтарын іске қосады. **Клиент** модтары PC нұсқасының мод жүктегішімен және Patcher-дің Android мод жүктегіш патчымен жұмыс істейді; екеуі де әзірлеу құрастырмаларында және келесі шығарылымдармен келеді.
:::

## Осы жерден бастаңыз

1. [Алғашқы Lua модыңыз](./mods/first-lua-mod): `bhmod new` бастап жұмыс істеп тұрған серверге дейін.
2. [Оқиғалар](./mods/events), [пәрмендер мен таймерлер](./mods/commands), [сақтау](./mods/storage).
3. [Басқа модтармен жұмыс](./mods/interop): сервистер, өз оқиғалар, арналар.
4. [Ыстық қайта жүктеу және уақыт өлшемдері](./mods/hot-reload): модты әлемді қайта қоспай өзгертіңіз.
5. Ашық тізімде [жариялау](./mods/publishing).

Rust ұнай ма? [Алғашқы Rust модыңызды](./mods/first-rust-mod) қараңыз. Барлық функциялар
[API анықтамасында](./mods/api/).

## Тараптар

Мод бір немесе екі **тарапта** жұмыс істейді:

- **server**: серверде жұмыс істейді.
- **client**: ойыншының құрылғысында, ойын ішінде жұмыс істейді (мод жүктегіш керек).
- **both**: сервер және клиент бөлігі бар. Оны *client-required* (клиентте міндетті) деп белгілеуге болады, сонда модсыз ойыншылар қосыла алмайды.

## Тілдер

**Lua (Luau)** — ең оңайы. **WebAssembly-ге (WASM) құрастырылған Rust** та жұмыс істейді; WASM компоненттерін жинай алатын C, Zig, Go және басқалары кейін қосылады. **Java** (және Kotlin немесе кез келген JVM тілі) де жұмыс істейді: `bhmod new my-mod --lang java` деп жазыңыз. Әртүрлі тілдегі модтар бір-бірін шақыра алады.

::: danger Java және нативті модтар құмсалғышсыз жұмыс істейді
**Java (JVM) модтары** және **нативті модтар** (ойынның өзін ұстап алады) сервердің немесе ойынның барлық құқығымен жұмыс істейді. Оларға `native` рұқсаты керек, **қызыл ескертумен** көрсетіледі және сіз қоспайынша өшірулі: JVM қолдауы — қосқыш (сервер: *Баптаулар > Java модтары*; PC Port: іске қосқыштың мод баптаулары; Android: Модтар экранындағы *Java модтары* қосқышы). Нативті модтар тек тексерілген жария тізімнен жүктеледі. Толығырақ: [JVM модтары](https://github.com/Blockheads-Club/mod-sdk/blob/dev/docs/jvm.md), [нативті модтар](https://github.com/Blockheads-Club/mod-sdk/blob/dev/docs/native.md).
:::

## mod.toml

Әр модтың `mod.toml` файлы бар. Негізгі өрістер:

| Өріс | Мағынасы |
| --- | --- |
| `id`, `version`, `name`, `description` | Модтың кім екені. Id кіші әріптерден, цифрлардан, `-` және `_` белгілерінен тұрады. |
| `authors`, `license` | Кім жасады және қандай лицензиямен. |
| `api` | Қай мод API нұсқаларымен жұмыс істейді, мысалы `^0.2` ([API нұсқалары](./mods/api-versions)). |
| `[sides]`, `[entry]` | Қайда жұмыс істейді және қай файлдан басталады. |
| `[dependencies]` | Оған қажет басқа модтар. |
| `[permissions]` | Оған не істеуге рұқсат (төменде). |

Толық пішім [SDK құжаттамасында](https://github.com/Blockheads-Club/mod-sdk/blob/dev/docs/package.md).

## Рұқсаттар

Мод тек рұқсаттары мүмкіндік беретінін ғана істей алады, әр рұқсатты сервер иесі береді:

- `world`: `none`, `read` немесе `write`.
- `players`: `chat`, `teleport`, `kick`, `ban`, `inventory`, `health` мәндерінің кез келгені.
- `net-http`: қосыла алатын сайттар.
- `channels`: сервер, клиенттер және басқа модтар арасындағы өз хабарлары.
- `native`: құмсалғыштан тыс нативті код. **Қызыл ескертумен** көрсетіледі және қолмен тексеріледі.

Тек қажетін ғана сұраңыз. Сервер иелері нені көреді: [Серверіңіздегі модтар](./mods/servers#permissions).
