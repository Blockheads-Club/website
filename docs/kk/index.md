## Blockheads Club деген не?

Blockheads Club — **The Blockheads** ойынын жақсы көретіндерге арналған, еріктілер жүргізетін ресми емес жоба. Біз үш
тегін құрал жасаймыз:

| Құрал | Не істейді | Қайда жұмыс істейді |
| --- | --- | --- |
| [PC нұсқасы](/kk/pc-port) | Android ойынын компьютерде іске қосады | Windows, macOS, Linux |
| [Патчер](/kk/patcher) | Android ойынының сіздегі көшірмесіндегі қателерді түзетеді | Веб, Windows, macOS, Linux, Android |
| [Сервер](/kk/server) | Көп ойыншы әлемдерін іске қосады | Windows, macOS, Linux, Docker, Android |

::: info Ойын — сіздікі
Біздің құралдардың ешқайсысында ойынның өзі жоқ. Сіз The Blockheads ойынының Android нұсқасының өз көшірмеңізді
(`.apk` файлын) қолданасыз: **1.7.4, 1.7.5 немесе 1.7.6** нұсқасы. Файлдарыңыз құрылғыңызда қалады, ешнәрсе
жүктелмейді.
:::

- **Компьютерде ойнағым келеді** → [PC нұсқасы](/kk/pc-port)

- **Достарыммен өз әлемімде ойнағым келеді** → [Сервер](/kk/server)
