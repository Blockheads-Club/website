# Қолтаңба кілтін сақтаңыз

Патчтаған әр ойынға тек құрылғыңызда сақталатын кілтпен қол қойылады. Сақтық көшірмесін жасап қойыңыз, сонда болашақ түзетулер жоймай-ақ орнатылады.

::: info Не қажет
- Blockheads Patcher (веб, компьютер немесе Android)
- Бір шағын файлға арналған қауіпсіз орын және есте сақтайтын құпиясөз
:::

## 1. Кілттің не істейтінін түсініңіз

Patcher кілтті бірінші патчтау кезінде жасайды. Android жаңартуды жөнделген ойынның үстіне **екеуіне де бір кілтпен қол қойылған** жағдайда ғана орнатады. Жаңа кілт қайтадан жоюды білдіреді — ал сақтық көшірмесіз жергілікті әлемдер жоғалады.

::: warning
**Құпия ұстаңыз.** Кілтіңіз барлар ойыныңыздың жаңартуы сияқты көрінетін қолданбалар жасай алады.
:::

## 2. Сақтық көшірмені экспорттаңыз

**Қолтаңба кілттері** бөлімін ашып, **Сақтық көшірмені экспорттау…** таңдаңыз. Құпиясөз қойып, қайталап, **Көшірмені сақтау** түймесін басыңыз. `.json` файлын аласыз, әдепкіде `blockheads-patcher-key.json`.

![Patcher-дің қолтаңба кілттері экраны: SHA-256 саусақ ізі бар кілт және құпиясөз өрістері мен сақтау түймесі бар сақтық көшірмені экспорттау формасы.](/shots/kk/patcher/keys-export.webp)

*Қолтаңба кілтінің құпиясөзбен қорғалған сақтық көшірмесін экспорттаңыз.*

::: tip
Құпиясөзді қалпына келтіре алмаймыз, сондықтан жазып қойыңыз. Құпиясөзсіз файл шифрланбайды және оны алған кез келген адам сіздің атыңыздан қолданбаларға қол қоя алады.
:::

## 3. Басқа құрылғыға көшіріңіз

Жаңа құрылғыда **Қолтаңба кілттері** бөлімін ашып, **Кілтті импорттау** таңдаңыз да, `.json` файлын көрсетіңіз. Сақтық көшірменің құпиясөзін енгізіп, **Осы кілтті қолдану** түймесін басыңыз.

Кілттің бірдей екеніне көз жеткізу үшін екі құрылғыдағы саусақ ізінің алғашқы және соңғы төрт жұбын салыстырыңыз.

## 4. Кілт жоғалса

Сақтық көшірмесіз сол кілтпен патчталған ойындарды жаңарта алмайсыз. Әлемдердің сақтық көшірмесін жасап, жөнделген ойынды жойыңыз да, жаңа кілтпен қайта патчтаңыз. [Әлемдерді қалай сақтауға болады](./backup-worlds)

## Бірдеңе дұрыс болмаса

- Patcher веб-нұсқасы кілтті осы сайтқа арналған браузер қоймасында сақтайды. Сайт деректерін тазалау оны жояды — алдымен сақтық көшірмені экспорттаңыз.
- Импорт тек Patcher экспорттаған `.json` сақтық көшірмелерін қабылдайды.
- Сұрақтарыңыз бар ма? [GitHub-та сұраңыз](https://github.com/Blockheads-Club/blockheads-patcher/issues).
