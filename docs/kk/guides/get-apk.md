# Өзіңізде бар ойынның APK файлын алу

Patcher-дің веб және компьютер нұсқаларына ойын `.apk` файлы ретінде керек. Android-та әдетте бұл нұсқаулықты өткізіп жіберуге болады.

::: info Не қажет
- Android телефонда орнатылған The Blockheads
- Компьютер арқылы жасау үшін: USB кабелі және Android-тың `adb` құралы
:::

## 1. Android-та ма? Орнатылған ойынды қолданыңыз

Android үшін Blockheads Patcher қолданбасы ойынды телефоннан өзі табады. **Орнатылған ойынды қолдану** түймесін басыңыз — файл керек емес. Немесе файл бұрыннан болса, **APK файлын таңдау** түймесін басыңыз.

## 2. Ойынды компьютерге көшіріңіз

Телефонда USB арқылы жөндеуді қосып, оны қосыңыз да, Android-тан ойынның қайда екенін сұраңыз. Содан кейін сол файлды көшіріңіз:

```sh
adb shell pm path com.noodlecake.blockheads
# package:/data/app/…/base.apk
adb pull /data/app/…/base.apk blockheads.apk
```

::: warning
Бірінші команда **бірнеше** жол шығарса, ойын бірнеше APK файлына бөлінген. Patcher оларды қауіпсіз патчтай алмайды — толық (әмбебап) APK қажет.
:::

## 3. Patcher-де ашыңыз

[Patcher веб-нұсқасын](https://blockheads.club/patcher/) немесе компьютер қолданбасын ашып, файлды тастаңыз. Ол **тек .apk файлдарын** қабылдайды. Ешнәрсе желіге жүктелмейді.

![Компьютердегі Patcher, ойын таңдау қадамы: The Blockheads APK файлын сүйреп әкелетін аймақ және файл таңдау түймесі.](/shots/kk/patcher/choose.webp)

*.apk файлын сүйреп әкеліңіз не таңдаңыз.*

::: tip
Тек өз көшірмеңізді пайдаланыңыз және APK файлын басқаларға таратпаңыз.
:::

## Бірдеңе дұрыс болмаса

- **«Телефоннан сақтаған The Blockheads ойынының .apk файлын таңдаңыз.»** — файл басқа қолданбаға тиесілі.
- **«Орнатылған ойын бірнеше APK файлына бөлінген…»** — орнына толық (әмбебап) APK беріңіз.
- Келесі: [Ойынды телефонда жөндеу](./fix-game-on-phone).
