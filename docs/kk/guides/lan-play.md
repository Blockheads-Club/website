# Достармен бір Wi-Fi желісінде ойнау

Үйдегі компьютерде серверді іске қосып, Wi-Fi желісіндегі әр телефонның бір әлемге қосылуына мүмкіндік беріңіз. Шамамен төрт минут алады.

::: info Не қажет
- Телефондармен бір Wi-Fi желісіндегі Windows, macOS немесе Linux компьютері
- Blockheads Server — компьютер қолданбасы немесе командалық жол сервері ([жүктеулер](https://github.com/Blockheads-Club/blockheads-server/releases))
- Әр телефонда The Blockheads. Заманауи Android-та [алдымен ойынды жөндеңіз](./fix-game-on-phone)
:::

## 1. Серверді іске қосыңыз

**Компьютер қолданбасы:** **Әлемдер** бөлімін ашып, **Әлем жасау** түймесін басыңыз, ат беріп, **Серверді іске қосу** түймесін басыңыз.

**Командалық жол:** компьютеріңізге арналған жүктеуді ашып, әлем жасаңыз. Сервер бірден іске қосылады:

```sh
# Linux / macOS, in the unpacked folder
./blockheads_server --new MYWORLD
# Windows (PowerShell)
.\blockheads_server.exe --new MYWORLD
```

![Компьютердегі Blockheads Server қолданбасы, әлем жасау терезесі: атауы, 1/16×-тен 16×-ке дейінгі өлшемі, сарапшы режимінің қосқышы және жасау түймесі.](/shots/kk/server/worlds-create.webp)

*Әлем жасау: атауы, өлшемі және қаласаңыз сарапшы режимі.*

::: tip
Командалық жол серверін `/stop` арқылы тоқтатыңыз. Ctrl + C оны соңғы сақтаусыз жабады.
:::

## 2. Брандмауэр арқылы рұқсат беріңіз

Сервер **UDP 15151 портын** пайдаланады. Windows брандмауэрі сұрағанда, **жеке желілерге** рұқсат беріңіз. Басқа жүйелерде брандмауэр болса, 15151 портында кіріс UDP-ге рұқсат беріңіз.

## 3. Сервер мекенжайын табыңыз

Компьютер қолданбасында **Шолу** бөлімінде **Телефоннан қосылу** картасы бар: онда **Жергілікті желі мекенжайы**, порт және QR код көрсетіледі. Мекенжайды көшіру үшін кодты телефон камерасымен сканерлеңіз.

Командалық жолда компьютердің жергілікті IP мекенжайын желі параметрлерінен қараңыз, мысалы `192.168.1.42`.

![Жұмыс істеп тұрған сервер тақтасы: күйі, желіде 2 ойыншы, жұмыс уақыты, ағымдағы әлем «Sunny Isle» және QR-коды, 192.168.1.42 мекенжайы мен 15151 порты бар телефоннан қосылу картасы.](/shots/kk/server/dashboard.webp)

*Тақтада жергілікті желі мекенжайы, порт және QR-код бар.*

## 4. Ойыннан қосылыңыз

Әр телефонда ойынды ашып, мына жерге өтіңіз:

- **Join World** → **Advanced...** → **Online IP/Port...**
- Мекенжай мен портты енгізіңіз (өрісте `15151` әлдеқашан жазулы)
- **Join Online World** түймесін басыңыз

::: tip
Серверде құпиясөз болса, ойын оны сұрайды.
:::

## Бірдеңе дұрыс болмаса

- **Ешкім қосыла алмайды** — телефондар бір Wi-Fi желісінде екенін (қонақ желісі емес) және брандмауэр UDP 15151 портына рұқсат беретінін тексеріңіз.
- **Бір дос қабылданбайды** — ақ тізімде аттар болса, тек сол аттар қосыла алады. [Админдер, модераторлар және бандар](./admins-mods) бөлімін қараңыз.
- Әлі шешілмеді ме? [GitHub-та хабарлап](https://github.com/Blockheads-Club/blockheads-server/issues), сервер журналын тіркеңіз.
