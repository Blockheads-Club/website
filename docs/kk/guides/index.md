# Нұсқаулықтар

Ойыншылар мен сервер иелеріне арналған қысқа суретті нұсқаулықтар. Әрқайсысында қанша уақыт кететіні және не қажет екені жазылған.

## Patcher

- **[Ойынды телефонда басынан аяғына дейін жөндеу](./fix-game-on-phone)** — Әлемдерді сақтау, патчтау, түпнұсқаны жою және жөнделген ойынды орнату.
- **[Патчтамас бұрын әлемдерді сақтау](./backup-worlds)** — Түпнұсқа ойын не үшін жойылуы керек және әлемдерді қалай сақтауға болады.
- **[Өзіңізде бар ойынның APK файлын алу](./get-apk)** — Орнатылған ойынды телефоннан компьютерге көшіру.
- **[Қолтаңба кілтін сақтаңыз](./signing-key)** — Жаңартулар неге сол кілтті қажет етеді және оны қалай экспорттап, импорттауға болады.

## Сервер

- **[Достармен бір Wi-Fi желісінде ойнау](./lan-play)** — Компьютерде серверді іске қосып, үйдегі әр телефоннан қосылыңыз.
- **[Raspberry Pi-да тәулік бойы сервер](./raspberry-pi)** — ARM нұсқасын орнатыңыз, жүктелгенде іске қосыңыз және автоматты сақтық көшірмелер жасаңыз.
- **[Серверді интернетке ашу](./open-internet)** — Портты бағыттау, құпиясөздер және ақ тізімдер, қадамдап.
- **[Админдер, модераторлар және бандар](./admins-mods)** — Кім не істей алады және ойыншыларды қолданбадан қалай басқаруға болады.
- **[Android телефонда сервер ашу](./host-android)** — Серверді Android тоқтатпай, фонда жұмыс істетіп қойыңыз.
- **[Docker және Docker Compose](./docker)** — Контейнер иелеріне арналған томдар, жаңартулар және журналдар.
