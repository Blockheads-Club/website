# Серверді интернетке ашу

Үйден тыс достарыңыз әлеміңізге қосыла алсын. Алдымен серверді қорғайсыз, содан кейін роутерде бір портты бағыттайсыз.

::: info Не қажет
- Wi-Fi желісінде жұмыс істейтін сервер ([LAN нұсқаулығы](./lan-play))
- Роутердің параметрлер бетіне қолжетімділік
:::

## 1. Алдымен серверді құлыптаңыз

**Құпиясөз** қойыңыз: қолданбада **Баптаулар** → **Құпиясөз** (15 таңбаға дейін), немесе консольде `/set-password` арқылы.

Немесе аттарды қосып, **ақ тізімді** іске қосыңыз: қолданбада **Кіру тізімдері** → **Ақ тізім**, немесе `/whitelist` арқылы. Ақ тізімде аттар пайда болғаннан бастап тек сол ойыншылар қосыла алады.

```text
# in the server console
/set-password secret123
/whitelist friendname
```

*Құпиясөз баптаулардағы қосылу бөлімінде.*

## 2. Серверге тұрақты мекенжай беріңіз

Роутерде сервер компьютерінің жергілікті IP мекенжайын резервте ұстаңыз (көбіне DHCP резервтеу деп аталады), сонда ол қайта қосылғаннан кейін өзгермейді.

## 3. Портты бағыттаңыз

Роутердің порт бағыттау бетінде **UDP 15151 портын** сервер компьютерінің жергілікті мекенжайына бағыттаңыз. Портты өзгерткен болсаңыз, өзіңіздікін қолданыңыз.

## 4. Жалпы мекенжайыңызбен бөлісіңіз

Жалпы IP мекенжайыңызды біліп, оны портпен бірге достарыңызға жіберіңіз. Олар **Join World** → **Advanced...** → **Online IP/Port...** арқылы қосылады.

::: warning
Жалпы IP мекенжайыңыз шамамен қай жерде екеніңізді көрсетеді. Оны тек сенімді адамдармен бөлісіңіз.
:::

## Бірдеңе дұрыс болмаса

- **Үйде істейді, сыртта істемейді** — роутердің интернет мекенжайы жалпы IP-ден өзгеше болуы мүмкін (кейбір провайдерлер бір мекенжайды бірнеше клиентке береді). Онда порт бағыттау жұмыс істемейді; провайдерден сұраңыз.
- **Әлі бұғатталған** — сервер компьютеріндегі брандмауэр UDP 15151 портына рұқсат беретінін тексеріңіз.
- Көмек керек пе? [GitHub-та хабарлаңыз](https://github.com/Blockheads-Club/blockheads-server/issues).
