# Android телефонда сервер ашу

Артық Android телефонды серверге айналдырыңыз. Blockheads Server қолданбасы фонда жұмысын жалғастырады, оны басқару үшін хабарландыру бар.

::: info Не қажет
- Wi-Fi желісіндегі Android телефон
- Blockheads Server APK (`blockheads-server-…-android.apk`, [шығарылымдар](https://github.com/Blockheads-Club/blockheads-server/releases))
- Зарядтағыш
:::

## 1. Қолданбаны орнатыңыз

APK жүктеп алып, ашыңыз. Android браузерден орнатуға рұқсат сұрауы мүмкін.

## 2. Әлем жасап, іске қосыңыз

**Әлемдер** → **Әлем жасау** бөлімін ашыңыз. Ат (30 таңбаға дейін) мен өлшемді таңдап, **Бұл әлемді бірден пайдалану** қосулы қалдырыңыз, содан кейін **Серверді іске қосу** түймесін басыңыз.

![Android телефонындағы Blockheads Server қолданбасы, әлемдер экраны: әлем жасау түймесі және «Sunny Isle» (қазір жүктелген) мен «Cozy Harbor» әлемдері.](/shots/kk/server/phone-worlds.webp)

*Әлем жасап, серверді іске қосыңыз.*

## 3. Фонда жұмыс істеуіне рұқсат беріңіз

Хабарландыру күйді, әлемді, қанша ойыншы желіде екенін және мекенжайды көрсетеді. Оның түймелері: **Серверді тоқтату**, **Мекенжайды көшіру** және **Консоль**.

::: tip
Сервер жұмыс істеп тұрғанда қолданба телефон мен оның Wi-Fi-ын ұйқыға жібермейді. Телефон оны бәрібір тоқтатса, Android параметрлерінде Blockheads Server үшін батарея оңтайландыруын өшіріңіз.
:::

## 4. Телефонды зарядта ұстаңыз

Сервер батарея зарядын көп жұмсайды. Достар ойнап жатқанда телефонды зарядта қалдырыңыз.

## 5. Достарыңызды қосыңыз

**Шолу** бетінде **жергілікті желі мекенжайы** мен QR код көрсетіледі. Басқа телефондарда **Join World** → **Advanced...** → **Online IP/Port...** арқылы қосылыңыз.

![Android телефонындағы сервер қолданбасының тақтасы: басқа телефондарға арналған жергілікті желі мекенжайы, порт және QR-код.](/shots/kk/server/phone-dashboard.webp)

*Достарыңыз тақтадағы мекенжаймен қосылады.*

## Бірдеңе дұрыс болмаса

- **«Сервер күтпеген жерден тоқтады»** — себебін көру үшін хабарландыруды басып, **Журналды ашу** таңдаңыз.
- Әлемдер осы телефондағы қолданбаның жеке қоймасында сақталады.
- Әлі шешілмеді ме? [GitHub-та хабарлаңыз](https://github.com/Blockheads-Club/blockheads-server/issues).
