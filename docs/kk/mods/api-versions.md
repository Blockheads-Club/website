# API нұсқалары

Мод API-ы `blockheads:api@<version>` ретінде нұсқаланады. Мод қай нұсқалармен жұмыс істейтінін `mod.toml` ішінде айтады:

```toml
api = "^0.2"
```

| Нұсқа | Не қосады |
| --- | --- |
| **0.1** | оқиғалар (қосылу, шығу, чат, пәрмен, тик, әлемді жүктеу және сақтау), пәрмендер, жоспарлағыш, сақтау, ойыншылар, журнал |
| **0.2** | ойын оқиғалары (кіру алдында, блок қою / алу / өзгеру, объект қою, зиян, өлім, қозғалыс), `player:pos()`, сервистер, өз оқиғалар, жергілікті арналар |
| **0.3** | клиент интерфейсі (`ui`), мод мазмұны және косметика (`content`) |
| **0.3.1** | желі арқылы сервистер: клиент моды мен сервер моды бір-бірін шақырады (`call-remote`, `cancel-remote`, `caller`); патч нұсқасы, басқа ештеңе өзгермейді |

## Үйлесімділік

- Серверлер **0.3.1 іске асырады және 0.3, 0.2 мен 0.1 де қолдайды**. 0.x ішінде жаңа минор нұсқа тек нәрсе **қосады**, сондықтан
  `api = "^0.1"` моды өзгеріссіз жүктеліп, жұмыс істей береді.
- 0.2-нің бірдеңесін қолданасыз ба? `api = "^0.2"` деп жазыңыз; 0.3 үшін `"^0.3"`, желі арқылы сервистер үшін `"^0.3.1"`. Сонда ескі серверлер модыңызды орындау кезінде
  құламай, өткізіп жібереді.
- 0.1 үшін құрастырылған WASM модтары жұмыс істей береді: серверлер қатырылған
  [0.1 WIT](https://github.com/Blockheads-Club/mod-sdk/tree/dev/wit/compat/blockheads-api-0.1.0) файлын да байлайды.
- `bh.host.api_version()` серверде қай нұсқа жұмыс істейтінін айтады.

Осы сайттағы анықтама **0.3.1** үшін: [API анықтамасы](./api/). 0.2 немесе 0.3-те жаңа функциялар мен өрістер
`(0.2)` немесе `(0.3)` деп белгіленген.
