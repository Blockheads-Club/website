# Серверіңіздегі модтар

::: warning Алдын ала нұсқа
[Blockheads Server](../server) әзірлеу құрастырмаларында **Lua** модтарын іске қосады; олар әлі шығарылымда жоқ.
**WASM** (Rust) модтары мен **клиент** модтары жақында.
:::

## Модтарды қосу

Модтар сервердің деректер қалтасындағы `mods` қалтасынан жүктеледі:

| Баптау | Модтар қалтасы |
| --- | --- |
| Компьютер / пәрмен жолы | `<data folder>/mods` (деректер қалтасы: `BLOCKHEADS_DATA_DIR`, болмаса үй қалтаңыздағы `GNUstep/Library/ApplicationSupport/TheBlockheads`) |
| Docker | томдағы `/data/mods` |
| Кез келген жерде | `BLOCKHEADS_MODS_DIR` айнымалысын басқа қалтаға орнатыңыз |

Модтар қалтасы жоқ болса (немесе бос болса) сервер дәл ванильдік сияқты жұмыс істейді: байттар, сақтаулар және шығыс бірдей.

## Модты орнату

1. `.bhmod` файлын <a href="../../../mods/" target="_self">Модтар бетінен</a> жүктеңіз (немесе автордан алыңыз).
   Ашылған мод қалтасы (ішінде `mod.toml` бар) да жарайды.
2. Оны модтар қалтасына салыңыз.
3. Рұқсаттарын `mods.toml` ішінде беріңіз (төменде).
4. Серверді қайта қосыңыз. Журналда `loaded 1 mod(s): …` немесе модтың неге жүктелмегені көрсетіледі.

Компьютер қолданбасында ашық тізімнен, файлдан не сілтемеден орнату жақында.

## mods.toml

`mods.toml` модтар қалтасында тұрады. Әр мод id-іне бір бөлім:

```toml
[hello-lua]
grant = ["players:chat"]

[noisy-mod]
enabled = false   # орнатулы қалады, бірақ жүктелмейді
```

Рұқсат қажет етпейтін модқа бөлім керек емес. Сіз бермеген рұқсатты сұрайтын мод **жүктелмейді**; оған тәуелді
модтар да өткізіліп кетеді.

## Рұқсаттар {#permissions}

| Рұқсат | Модқа мүмкіндік береді |
| --- | --- |
| `players:chat` | барлығына чат хабарларын жіберу |
| `players:kick`, `players:ban` | ойыншыларды кик немесе бан жасау |
| `players:teleport`, `players:inventory`, `players:health` | ойыншыларды жылжыту, инвентарьды немесе денсаулықты өзгерту |
| `world:read`, `world:write` | әлемді оқу немесе өзгерту (`world:write` `world:read` дегенді де қамтиды) |
| `net-http:<host>` | сол сайтқа қосылу |
| `channels` | басқа модтарға және клиенттерге хабар жіберу |
| `native` | құмсалғыштан тыс нативті код іске қосу (**қызыл ескерту**, қолмен тексеріледі) |

Қалғанының бәріне рұқсат керек емес: оқиғалар, өз пәрмендері, таймерлер, өз сақтауы, бір ойыншыға чат және
тәуелді модтардың сервистері. Модтың ашық тізімдегі бетінде оның нені сұрайтыны көрсетіледі.

## Уақыт пен жад шектеулері {#time-and-memory-limits}

Модтар сервердің негізгі ағынында жұмыс істейді, сондықтан әрқайсысы қатаң шектеледі:

- Модқа әр шақыру **25 мс** алуы мүмкін (5 мс-тан кейін журналға ескерту жазылады).
- Барлық модтар бірге әлемнің бір қадамына **20 мс** алады; одан асқан таймерлер келесі қадамды күтеді.
- Әр модқа **32 MiB** жад беріледі.

Қате, уақыт асып кету немесе жадтың таусылуы **ақау** деп саналады. **60 с ішінде 3 ақау модты** келесі қайта
қосуға дейін **өшіреді**; журналда `disabled: 3 faults within 60 s` және қате аты жазылады. Мұны модтың авторына хабарлаңыз.

## Сақтау

Әр мод өз деректерін әлем бойынша `saves/<world>/mods/storage` ішінде сақтайды, әлемнің өзінен бөлек. Оны жою
модтардың деректерін тазалайды, әлемге тиіспейді. Резервтік көшірмені әлеммен бірге жасаңыз.

## Ванильдік ойыншылар

- **Тек сервер модтары:** кез келген адам қарапайым ойынмен қосыла алады.
- **Клиентте міндетті модтар** <Badge type="warning" text="жақында" />: мод жүктегіші жоқ ойыншылар қайтарылады
  (ойыны клиенттің ескіргенін айтады). Модтың бетінде мұндай модтар *client-required* деп белгіленеді.
