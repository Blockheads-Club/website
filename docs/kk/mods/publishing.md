# Жариялау

Ашық тізім [Blockheads-Club/mods](https://github.com/Blockheads-Club/mods) репозиторийінде тұрады және
<a href="../../../mods/" target="_self">Модтар бетінде</a> көрсетіледі. Модтар pull request арқылы қосылады.

## Жібермес бұрын

- `LICENSE` файлын қосыңыз (қалаған лицензияңыз).
- `.bhmod` файлын HTTPS арқылы ашық жерге қойыңыз, мысалы GitHub шығарылымының файлы ретінде. Біріктірілгенде көшірмесі жасалады.
- Ашық тізім ережелерімен тексеріңіз:

  ```sh
  bhmod check . --index
  bhmod pack .
  ```

## Жіберу

1. Модыңыздың мәліметтері, жүктеу URL-ы, SHA-256 және өлшемі бар `mods/<first letter>/<id>.toml` деген бір файл қосыңыз.
2. Pull request ашыңыз. CI жазбаны және пакетті тексеріп, сұралған рұқсаттармен пікір қалдырады.
3. Мейнтейнер әр **жаңа** модтың (және рұқсат не нативті код қосатын жаңартулардың) кодын тізімге қосар алдында оқиды.

Модыңыздың атауы мен сипаттамасы басқа тілдерде де көрінсін бе? Жазбаға `name` және/немесе `description` бар
`[i18n.tr]`, `[i18n.ru]`, `[i18n.kk]` ... кестелерін қосыңыз. Оқырмандар өз тілін көреді, жетіспейтіні үшін ағылшын
тілі қолданылады; оларды кез келген уақытта өзгертуге болады.

Барлық өрістер мен мысал: <a href="../../../mods/submit" target="_self">Мод жіберу</a>.

## Жаңартулар

- Жазбаңызға жаңа нұсқа қосыңыз; жарияланған нұсқалар ешқашан өңделмейді немесе жойылмайды.
- Бұзылған нұсқаны `yanked = true` деп белгілеуге болады.
- Жазбаны тек модтың `owners` өзгерте алады.

CI-дағы тексерулерді жергілікті іске қосыңыз: [`bhmod index validate`](https://github.com/Blockheads-Club/mod-sdk/blob/dev/docs/index.md).
